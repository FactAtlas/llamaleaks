Privacy Policy

Last updated: November 26, 2026

This policy describes how Llama Leaks Uploader (the "App") and this website handle information. The App is a private tool operated by the owner of the Llama Leaks TikTok account and is used exclusively to manage that account.

1. Data the App accesses

With the account owner's explicit consent via TikTok Login Kit, the App uses the TikTok API to:

  • read basic profile information of the owner's account (display name, avatar, open ID),
  • upload videos with captions to the owner's own TikTok account (as drafts or posts).

The App does not access, collect or store data of any other TikTok user.

2. How data is stored

Access tokens and a list of uploaded videos are stored only locally on the owner's computer. No data is sent to any server other than TikTok's APIs. No data is sold, shared with third parties or used for advertising.

3. Revoking access

Access can be revoked at any time in the TikTok app under Settings → Security → Manage app permissions.

4. This website

This website is a static page hosted on GitHub Pages. It uses no cookies, no analytics and no tracking. GitHub may log technical data such as IP addresses for security purposes; see the GitHub Privacy Statement.

5. Contact

Via TikTok direct message to @llamaleaks.
