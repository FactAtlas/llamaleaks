About

Llama Leaks is a TikTok channel with short videos about the latest Fortnite news: updates, new skins, item shop, events and community trends. Videos are produced with automated tools: scripts are drafted with AI assistance from public sources and narrated with a synthetic version of the creator's own voice.

Llama Leaks Uploader

Llama Leaks Uploader is a private tool used only by the channel owner. It uses the TikTok Content Posting API to send videos created by the owner to the owner's own TikTok account. It does not access data of any other TikTok user.
